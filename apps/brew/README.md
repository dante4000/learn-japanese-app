# brew

A batch calculator for traditional Korean rice wine (전통주).

Pick a recipe, set your target rice weight, and brew scales every stage —
rice, water, and nuruk — across each mashing (밑술 + 덧술). Eight classical
recipes reconstructed from Korean source texts, with tasting notes, technique,
and history for each.

## Recipes

오양주 · 삼해주 · 석탄주 · 약산춘 · 백하주 · 벽향주 · 호산춘 · 교동법주

## Develop

```bash
npm install
npm run dev
```

Open http://localhost:3000.
